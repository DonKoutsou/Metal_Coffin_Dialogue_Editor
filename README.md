# Metal Coffin Dialogue Editor

This is a tool wich is part of the Metal Coffin's SDK for modding.

## Packer
The unpacker/packer will be found here, this can be used to unpack the game files and afterwards pack your changes in a mod that can be used in the game.
[Metal Coffin Mod Packer](https://github.com/DonKoutsou/MetalCoffin-Mod-Packer)


## Other Tools
The unpacked files can be manually modified or the Official tools can be used instead.
* [Card Builder](https://github.com/DonKoutsou/Metal_Coffin_Card_Builder)
* [Item Builder](https://github.com/DonKoutsou/Metal_Coffin_Item_Builder)
* [Captain Creator](https://github.com/DonKoutsou/Metal_Coffin_Captain_Creator)
